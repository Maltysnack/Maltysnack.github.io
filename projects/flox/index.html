Project

Flox

A small language for flow networks. You write nodes and arrows, and it simulates how something moves through them over time.

Every example is live. Edit the program and the output reruns.

River

The default mode. Two rivers, one dam and an outlet take a five-day rainfall pulse; the table is the flow each day.

Markov

The same arrows carry probabilities. A footballer passes again or shoots, and within 200 ticks the chain settles into a goal or miss split.

Grid

compare runs one network under several scenarios side by side: the baseline, the main plant offline, and the tie line cut.

Grammar

mode river|markov|grid;Picks the simulator. River if absent.
system Name;Starts a system. Everything after attaches to it.
A -> B -> C;A chain of edges, weight 1. A -[w]-> B sets a weight; <- points the other way.
river Name { ... }base and peak required, decay optional (0 to 1, default 0.7).
dam Name { ... }capacity in ML, threshold as 80% or 0.8, normalRate and openRate in ML/day.
outlet Name;Collects everything that reaches it.
node Name { supply: n }A generic state. In grid mode, supply is positive for generators and negative for loads, and must sum to zero.
start Name mass;Markov only: initial probability mass.
print Name n;Runs it. River: n mm of rain on day 1, or [r1, r2, ...] per day. Markov and grid: tick budget.
compare Name n as ...;Scenarios side by side, each "Label" with disable X or disable A -> B.
list Name; map Name;Lists the nodes and their edges, or draws the network.
